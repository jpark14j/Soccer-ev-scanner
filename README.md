# BetMGM Ontario soccer scanner

Replace your GitHub repository `app.py` and `requirements.txt` with these files. Set `ODDS_API_KEY = "..."` in Streamlit Community Cloud Secrets (never GitHub). Click Find +EV Bets to request Canadian 1X2 odds, filter BetMGM Ontario, and estimate probabilities using no-vig averages from other books. Requires the API to return BetMGM Ontario and comparable reference books. Not an independent model, not guaranteed profitable. No player props or parlay scanner.
